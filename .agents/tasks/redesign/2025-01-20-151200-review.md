## Supplier product image upload with preview and limits

Supplier.jsx SupplierStock component implements full image upload flow:

**File input**:
```jsx
<input 
  type="file" 
  accept="image/jpeg,image/png,image/webp" 
  multiple 
  onChange={handleImageUpload} 
/>
```

**Upload handler**:
- Slices first 5 files: `Array.from(e.target.files).slice(0, 5)`
- Validates each file size: `if (file.size > 2 * 1024 * 1024) { setMsg(...); return; }`
- Converts to base64: FileReader readAsDataURL, onload appends to images state array
- Stores as data URLs: `data:image/jpeg;base64,...`

**Preview grid**:
- Grid layout: `gridTemplateColumns: "repeat(auto-fill, minmax(120px, 1fr))"`
- Each image card: 120px min-width, 100px height thumbnail
- Primary image: 3px solid primary border, "★ Primary" button
- Non-primary: 1px line border, "Set Primary" button
- Delete button: red, positioned bottom-right, removes image and adjusts primaryImageIndex

**Form submission**:
```js
const body = {
  ...form,
  images,
  primaryImage: images[primaryImageIndex] || null
};
await api("/supplier/inventory", { method: "POST", body });
```

Backend Inventory.js model:
```js
images: { type: [String], default: [] },
primaryImage: { type: String, default: null }
```

Supplier inventory table displays thumbnails:
```jsx
<img 
  src={row.primaryImage} 
  alt="Product" 
  style={{ width: "50px", height: "50px", objectFit: "cover", borderRadius: "4px", cursor: "pointer" }} 
  onClick={() => window.open(row.primaryImage)}
/>
```
